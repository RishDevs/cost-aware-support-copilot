# Returns Policy

## Overview

ShopEase offers a flexible return policy designed to ensure customer satisfaction. Please review the guidelines below before initiating a return.

## Standard Return Window

Most items purchased from ShopEase can be returned within **30 days** of the delivery date, provided the items meet the return eligibility criteria listed below.

## Return Eligibility

To be eligible for a return, items must:

- Be in their **original, unused condition**
- Include all **original packaging**, accessories, and documentation
- Have proof of purchase (order number or receipt)
- Not be classified as a non-returnable item (see below)

## Category-Specific Return Windows

Different product categories have different return policies:

| Category | Return Window | Condition Required |
|----------|--------------|-------------------|
| Electronics | 30 days | Unopened or defective only |
| Apparel & Shoes | 60 days | Unworn, with tags attached |
| Books & Media | 30 days | Unopened only |
| Appliances | 30 days | Unused, original packaging |
| Furniture | 14 days | Unassembled only |
| Jewelry | 30 days | Unworn, original packaging |
| Perishables | Not returnable | N/A |
| Software / Digital | Not returnable | N/A |
| Personalized items | Not returnable | N/A |

## Non-Returnable Items

The following items **cannot be returned** under any circumstances:

- Perishable goods (food, flowers, etc.)
- Digital downloads and software licenses
- Personalized or custom-engraved items
- Hazardous materials (batteries shipped separately, flammable liquids)
- Gift cards and store credits
- Items marked "Final Sale"

## How to Initiate a Return

1. Log in to your ShopEase account.
2. Navigate to **Orders > Return an Item**.
3. Select the item(s) you wish to return and state the reason.
4. Print the prepaid return shipping label (provided instantly for eligible returns).
5. Drop the package at any authorized carrier location within **7 days** of label generation.
6. Refunds are processed within **5–10 business days** after we receive the item.

## Return Shipping Costs

- **Free returns**: Apparel, Shoes, and defective/damaged items.
- **Customer pays return shipping**: All other categories (we provide a discounted label).
- **ShopEase pays return shipping**: If the return is due to our error (wrong item sent, damaged in transit).

## Holiday Return Policy

Items purchased between **November 15 and December 31** can be returned until **January 31** of the following year, regardless of the standard return window.

## Return Exceptions — Handling Edge Cases

### Electronics Opened Before Defect Discovered

Electronics that develop a manufacturing defect within the return window may be returned even if opened, provided:

- The defect is verified by our returns team.
- The item has not been physically damaged by the customer.

### Used vs. Defective

- A **used** item returned claiming it's defective will be inspected by our team.
- If found genuinely defective: full refund issued.
- If found in working condition and used: return may be denied.

### Partial Returns

For bundle purchases, you may return individual items from a bundle, but the refund will reflect the prorated value of the returned item(s), not the total bundle price.

## Regional Policy Notes

- **California customers**: Additional statutory rights apply under California consumer protection law.
- **International orders**: May be subject to local import duties upon return. ShopEase does not cover these costs.
